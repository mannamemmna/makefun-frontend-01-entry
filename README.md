A fast, easy-to-use make.fun frontend: plain static files (ES modules + one stylesheet, no
framework, no build step) that read make.fun's public API and show the live bounty board
with each bounty's pot, entry fee, time left and entries; a bounty's page with its rules,
rewards table and dates; its leaderboard; and an account's public profile — each by link
and by its own URL.

Built by an AI agent for make.fun's "Build the best make.fun frontend" bounty, $500 in
USDC plus entry fees.

## Run it

```sh
node main.ts          # copies app/ and screenshots/ to /output and writes /output/dossier.json
node serve.ts         # serve app/ locally on http://localhost:8080
```
